# 波士顿矩阵 — BCG Matrix

## 一句话定义

用两个维度（增长空间 × 竞争优势）把选项分成四类，判断哪些值得投入、哪些该放弃。

## 何时用

- 选项太多，资源有限，需要做取舍时
- 不清楚该继续投入还是及时止损

## 核心模型 / 结构式

|            | 高增长               | 低增长             |
| ---------- | -------------------- | ------------------ |
| **高份额** | ⭐ 明星 — 重点投入   | 🐄 金牛 — 收割利润 |
| **低份额** | ❓ 问题 — 选择性投入 | 💀 瘦狗 — 考虑放弃 |

## 一句话案例

写博客（明星：有基础 + 有增长空间）→ 继续投入 / 接外包（瘦狗：有收入但无增长）→ 果断放弃。

## 在循环中的位置

选方向环节的评估工具。配合黄金圈使用——黄金圈找到"想做的"，波士顿矩阵判断"该做的"。输出进入定计划环节。
