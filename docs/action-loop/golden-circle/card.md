# 黄金圈 — Golden Circle

## 一句话定义

从 Why（为什么）出发，而不是从 What（做什么）出发——先找到驱动理由，再设计怎么做，最后决定做什么。

## 何时用

- 面对多个选择，不知道哪个方向真正适合自己
- 正在做的事让你觉得没动力、没意义
- 需要说服别人（或自己）相信一件事值得做

## 核心模型 / 结构式

```
Why（信念/理由）→ How（策略/方式）→ What（行动/产品）
```

从内向外思考，而不是从外向内。

## 一句话案例

苹果的 Why 不是"做最好的电脑"，而是"挑战现状"——所以他们做出了 iPod、iPhone 等颠覆性产品。

## 在循环中的位置

选方向环节的核心工具之一。黄金圈帮你找到"为什么做"，再配合波士顿矩阵判断"值不值得做"，输出给定计划环节。
