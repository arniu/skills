# WOOP — 实操指南

## 概述

WOOP 是"定计划"和"日执行"之间的桥梁。它解决一个经典问题：计划做得很完美，但执行时一碰到障碍就放弃了。

WOOP 让你在行动之前，就在大脑中预演一遍"障碍场景 + 应对动作"。这不是悲观——这是给大脑装一个紧急出口，让障碍来临时你不必临时想对策。

## 核心概念

WOOP 由心理学家 Gabriele Oettingen 提出，四个步骤：

| 步骤         | 含义                   | 作用     |
| ------------ | ---------------------- | -------- |
| **W**ish     | 一个具体且有挑战的愿望 | 锁定目标 |
| **O**utcome  | 实现愿望的最佳结果     | 提供动力 |
| **O**bstacle | 阻碍实现的关键障碍     | 提前预警 |
| **P**lan     | 如果障碍发生，怎么办   | 自动触发 |

**关键机制**：第三步（障碍）和第四步（计划）一起形成**实施意向**（Implementation Intention）——大脑把"障碍 → 动作"编码成一个自动反应，不再需要意志力做决策。

## 操作步骤

### 第一步：写下一个愿望（W）

从 SMART 计划中选一个近期目标，用一句话写成 Wish。例如："连续 30 天，每天写 500 字。"

### 第二步：想象最佳结果（O）

闭上眼睛，想象愿望实现后的场景。感受那个场景里的情绪——兴奋、满足、自豪？写下来。这一步提供情感动力。

### 第三步：找出关键障碍（O）

问自己："很可能是什么会拦住我？"

- 找**内部障碍**（自己的行为、情绪、习惯），而非外部借口
- 最真实的那个障碍往往让你有点不舒服——那就是它

### 第四步：写 If-Then 计划（P）

把障碍和行动写成 If-Then 句式。关键：

- If 要具体："如果晚上 10 点还没开始写"
- Then 要可执行："那么我不开电脑，用手机备忘录写 100 字就行"

### 第五步：在心里演练一遍

在心里跑一遍：障碍出现 → 自动触发 Then。多跑几遍，让大脑建立新的神经联结。

## 真实案例

**背景**：设计师小张制定了一个 SMART 计划"每周五下午发布一篇设计复盘文章"。

**WOOP 过程**：

| 步骤         | 内容                                                                 |
| ------------ | -------------------------------------------------------------------- |
| **W**ish     | 连续 8 周，每周五出一篇设计复盘                                      |
| **O**utcome  | 积累作品集、被同行认可、获得更多项目机会                             |
| **O**bstacle | 周四经常甲方改需求，周五早上还在赶稿，没时间写                       |
| **P**lan     | 如果周四甲方改需求超过 2 轮，那么我周五早起 1 小时在 10 点前写完初稿 |

**结果**：第二周果然改需求了，他自动按照 Plan 早起完成——没有因为临时变故而放弃。

## 常见误区

1. **写外部障碍**
   "领导不给资源""市场不好"——WOOP 要找自己可控的障碍。外部因素你无法通过 If-Then 解决。

2. **障碍找得太表面**
   "我没时间"——"没时间"不是障碍，是结果。真正的原因是"我优先做了别的事"或"这件事让我焦虑所以我拖延"。

3. **Then 写得太笼统**
   "那就努力坚持"——没有具体动作的 Then 等于没有。写一个你能立刻执行的物理动作（"打开电脑→打开文档→写第一行"）。

4. **不动手写，只在脑子里想**
   写下来的 If-Then 才真正生效。手写或者打出来，放在每天能看到的地方。

## 与循环中其他模型的关系

WOOP 承接 SMART 的产出。做完 WOOP 后，进入**日执行**环节用微习惯落地。如果 WOOP 发现的障碍太严重（比如资源完全不够），可能需要回到**定计划**环节调整目标。
