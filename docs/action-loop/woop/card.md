# WOOP — WOOP

## 一句话定义

在启动计划之前，提前想象可能遇到的障碍，并写好"如果…那么…"的应对方案。

## 何时用

- 计划已定，准备执行之前
- 过去经常在某个环节掉链子

## 核心模型 / 结构式

```
Wish（愿望） → Outcome（最佳结果） → Obstacle（障碍） → Plan（计划）
```

**Plan 的核心句式**：

> 如果 **[障碍 X 发生了]**，那么我就 **[做 Y]**。

## 一句话案例

Wish："每周跑步 3 次" / Outcome："精力充沛、体检指标改善" / Obstacle："加班太晚没精力跑" / Plan："如果超过 9 点下班，那么我就换上跑鞋走回家，不坐车。"

## 在循环中的位置

在"定计划"之后、"日执行"之前。用 WOOP 过一遍计划，把"我知道会出问题的地方"提前写好应对方案。
