# 微习惯 — Mini Habits

## 一句话定义

把一个行为缩小到"小到不可能失败"的程度，每天做，先动起来再说。

## 何时用

- 知道该做什么，但就是不想开始
- 曾经多次尝试建立某个习惯都失败了
- 面对一个大任务感到抗拒和拖延

## 核心模型 / 结构式

```
微习惯 = 缩小到难以拒绝 × 每天重复
```

缩小的原则：**低于你意志力的最低点**

- 想跑步 → 穿上跑鞋（甚至只跑 1 分钟）
- 想写作 → 写 50 个字（不是一篇）
- 想学习 → 打开书读 1 段

## 一句话案例

"每天写 1000 字"坚持不了 → 改成"每天写 50 字"，结果经常写了 500 字才停——因为最难的是开始的那 50 字。

## 在循环中的位置

日执行是计划落地的一线。微习惯承接 WOOP 的输出，把计划压缩到每天的最小行动单元。执行结果进入**周复盘**环节做 PDCA 评估。
