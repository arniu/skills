# 微习惯 — 实操指南

## 概述

我们常常以为"做不到是因为不够自律"。但微习惯告诉你另一个答案：**做不到是因为起步门槛太高。**

你的意志力每天不一样——加班后、没睡好、压力大的时候，意志力见底。如果你指望每天都有满格意志力去完成一个宏伟的计划，注定会失败。

微习惯的策略是：把门槛降到意志力低谷时也能轻松跨过去。一旦开始做，你往往会做得比计划多——但就算只做了那个"最小动作"，也算完成了。

## 核心概念

### 微习惯的原理

微习惯基于两个脑科学事实：

1. **基底神经节**负责自动行为——一旦启动就自动运行
2. **前额叶皮层**负责有意识决策——容易疲劳

微习惯绕过前额叶（不需要做"要不要开始"的决策），直接欺骗基底神经节启动。一旦启动了，继续做比停下来更容易。

### 微习惯的两个铁律

1. **绝不要提高预期**——微习惯就是"只做最小量"，不能因为某天做多了就把标准提高
2. **绝不要觉得"太简单没用"**——做了就比没做强

## 操作步骤

### 第一步：选一个想建立的习惯

从 SMART 计划中选一个可以每天执行的行为。比如"写博客"→ 每天的一个行为是"写"。

### 第二步：缩小到难以拒绝

把它缩小到：

- **你状态最差的时候也能完成**
- **不超过 2 分钟**
- **不会触发你的抗拒心理**

举例：

| 原计划            | 微习惯                 |
| ----------------- | ---------------------- |
| 每天跑步 5 公里   | 穿上跑鞋               |
| 每天写 1000 字    | 写 50 字               |
| 每天学 1 小时英语 | 打开 App 完成 1 个练习 |

### 第三步：设定时间和触发器

时间："每天吃完早餐后" / 触发器：跟已有习惯绑定（习惯堆叠）

### 第四步：记录

每天做完后打个勾。连续记录带来正向反馈。

### 第五步：允许超额但不提高标准

某天状态好，跑了 10 公里 → 很棒，但明天的微习惯还是"穿上跑鞋"。超额是奖励，不是新标准。

## 真实案例

**背景**：产品经理老李想养成写作习惯，之前尝试过"每天写一篇 1500 字的文章"，坚持了 3 天就放弃了。

**微习惯转型**：

- 缩到最小："每天写 50 字，主题不限"
- 触发器："每天早上到工位->打开文档写 50 字->关掉"
- 前两周：确实只写了 50 字，但每天都在做
- 第三周开始：经常写着写着写到 300-500 字
- 两个月后：习惯已经固定，每天稳定输出 500-1000 字

关键转折：第三周的那次"超额"是因为 50 字实在太轻松了，轻松到大脑觉得"再写几句也不亏"。

## 常见误区

1. **缩得不够小**
   "每天写 500 字"不是微习惯，你状态差的时候绝对做不到。50 字、20 字甚至一句话才是。

2. **偷换概念提高标准**
   某天超额了，第二天心想"既然我昨天能跑 5 公里，今天至少 3 公里"——微习惯立刻失效。标准一旦提高，就不再有"小到不可能失败"的效果。

3. **同时开始多个微习惯**
   一次只培养一个。等一个变成了自动行为（通常 6-8 周），再加第二个。

4. **不做记录**
   微习惯的正反馈来自"连续完成"的视觉记录。不记录就得不到这个反馈。

## 与循环中其他模型的关系

日执行是 WOOP 的落地执行阶段。执行中遇到的意外障碍记录下来，进入**周复盘**环节做 PDCA 分析。如果某个微习惯连续两周无法坚持，说明缩得还不够小，或者方向（选方向环节）需要重新审视。
