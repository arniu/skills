# 精力金字塔 — Energy Pyramid

## 一句话定义

人的精力有四个维度（身体、情感、心理、精神），底层不稳上层就塌。优先睡好觉，把难事安排在精力峰值时段。

## 何时用

- 感觉疲惫、效率下降、做什么都提不起劲
- 执行计划时经常"有心无力"

## 核心模型 / 结构式

```
     精神能量（意义感）
       ↑
     心理能量（专注力）
       ↑
     情感能量（关系质量）
       ↑
  ⚡ 身体能量（睡眠、饮食、运动） ← 基础
```

下层支撑上层：身体不好 → 情感不稳 → 无法专注 → 找不到意义。

## 一句话案例

连续熬夜赶项目 → 白天脑子转不动（心理）→ 容易烦躁（情感）→ 怀疑自己在做什么（精神）→ 实际上是从底层（身体）塌了。

## 在循环中的位置

保状态是 Action Loop 的**基础设施**。它不直接参与其他环节，但决定其他环节能否有效运转。状态不好时，先回到这里，而不是硬推其他环节。
