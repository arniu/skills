# 精力金字塔 — 实操指南

## 概述

Action Loop 的前五个环节（选方向→定计划→破障碍→日执行→周复盘）都默认一个前提：**你有精力去做**。但如果身体和状态垮了，再好的计划也没用。

精力金字塔是 Jim Loehr 和 Tony Schwartz 在《The Power of Full Engagement》中提出的框架。核心观点是：**管理精力，而不是管理时间。** 时间有限，精力可以被补充和扩容。

## 核心概念

精力金字塔有四层，从底到顶：

| 层级     | 内容               | 核心问题             | 恢复方式                      |
| -------- | ------------------ | -------------------- | ----------------------------- |
| **身体** | 睡眠、饮食、运动   | 我的身体燃料够吗？   | 睡够 7-8h、规律运动、均衡饮食 |
| **情感** | 人际关系、情绪状态 | 我的情绪电池有电吗？ | 高质量的社交、放松、爱好      |
| **心理** | 专注力、认知负荷   | 我的大脑还能转吗？   | 单任务、休息间隔、减少决策    |
| **精神** | 意义感、价值感     | 我为什么在做这件事？ | 连接 Why、做有意义的事        |

**底层支撑上层**：睡不好 → 情绪容易崩 → 无法专注 → 怀疑人生意义。反过来：找到意义 → 更有动力 → 更专注 → 更愿意维护身体。

**关键原则**：精力需要"消费+恢复"的节奏，而不是持续消耗。工作 90 分钟休息 15 分钟，比持续工作 3 小时总产出高。

## 操作步骤

### 第一步：诊断当前状态

对四个层级逐一打分（1-10），找到最薄弱的底层：

- 身体：睡眠质量？运动频率？饮食规律？
- 情感：最近跟家人/朋友关系如何？工作情绪稳定吗？
- 心理：每天能专注几小时？经常被打断吗？
- 精神：最近做的事有意义吗？跟你的 Why 一致吗？

**最薄的那个层级**是你的瓶颈——优先处理它。

### 第二步：修复底层

如果身体层低于 6 分，先做这三件事（优先级从高到低）：

1. **睡眠**：固定作息，7-8 小时，雷打不动
2. **运动**：每周至少 3 次有氧，每次 20 分钟
3. **饮食**：三餐规律，减少高糖/高油

### 第三步：安排精力峰值时段

每个人一天中有精力最充沛的时段。把最重要的任务安排在这个时段，而不是按照"上午做最难的事"的教条。

- 观察自己一周，记录精力高低点
- 把需要深度思考的事放在峰值
- 把机械/社交/沟通放在低峰

### 第四步：建立恢复节奏

- **每 90 分钟**：离开座位 5-10 分钟
- **午间**：20 分钟午休（不要刷手机）
- **晚间**：睡前一小时远离屏幕
- **每周**：留一天不工作相关的思考/活动

### 第五步：定期校准

每周复盘时顺便检查：这周精力状态怎么样？哪个层级在报警？

## 真实案例

**背景**：小陈最近几周 Action Loop 执行得很吃力——每天写 50 字的微习惯都坚持不了。

**诊断**：

| 层级 | 分数 | 问题                            |
| ---- | ---- | ------------------------------- |
| 身体 | 4    | 连续 2 周 <6h 睡眠，咖啡当水喝  |
| 情感 | 6    | 跟同事关系还行，但回家不想说话  |
| 心理 | 5    | 注意力涣散，15 分钟就刷一次手机 |
| 精神 | 7    | 对工作还有意义感                |

**根因**：身体层是瓶颈。不是意志力问题，是身体燃料不够。

**行动**：

1. 强制 11 点睡，7 点起（至少 7 小时）
2. 中午散步 15 分钟
3. 下午 2-4 点最难的任务改到早上 9-11 点（他的精力峰值）

**结果**：两周后身体分从 4 → 7，微习惯重新持续执行。

## 常见误区

1. **忽视底层，在上层使劲**
   睡眠不足却学时间管理技巧——没用。先从睡觉开始。

2. **把咖啡因当精力来源**
   咖啡不是补充精力，是透支未来的精力储备。长期靠咖啡因维持的人，底层已经垮了。

3. **持续消耗不恢复**
   "干完这票就休息"的心态。精英运动员不是训练时间最长的人，而是恢复做得最好的人。

4. **忽视情感层的影响**
   一段糟糕的关系比缺觉更容易让人精疲力尽。有时候状态不好不是身体问题，是情绪在消耗你。

## 与循环中其他模型的关系

精力金字塔是其他所有环节的**运行环境**。如果连续几周 PDCA 发现执行率严重低于预期，而且 WOOP 和微习惯调整都无效——检查精力状态，问题可能在这里。
