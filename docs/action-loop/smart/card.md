# SMART — SMART Criteria

## 一句话定义

把模糊的愿望翻译成具体、可衡量、可达成、相关且有截止日期的目标。

## 何时用

- 方向确定后，需要拆成可执行的计划时
- 跟人约定目标时，需要对齐预期

## 核心模型 / 结构式

```
SMART = S · M · A · R · T
        具体 · 可衡量 · 可达成 · 相关 · 有时限
```

模板句式：

> 在 **[截止日期]** 前，将 **[具体对象]** 从 **[当前状态]** 推进到 **[可衡量的目标状态]**，且与 **[更大目标]** 一致。

## 一句话案例

"我要提升写作"（模糊）→ "未来 30 天在博客发布 6 篇技术文章，每篇 >1000 字"（SMART）。

## 在循环中的位置

承接"选方向"输出的优先方向，把方向拆成可衡量的目标。输出给"破障碍"环节做 WOOP 分析。
