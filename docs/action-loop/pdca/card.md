# PDCA — PDCA 循环

## 一句话定义

每周花 30 分钟，回顾过去一周的执行情况，找出问题和改进点，调整下周计划。

## 何时用

- 每周固定的复盘时间（推荐周日晚上）
- 一个阶段结束后做项目级复盘

## 核心模型 / 结构式

```
Plan（计划）→ Do（执行）→ Check（对比分析）→ Act（调整）
           ↺ 持续循环
```

- **P**：上周计划是什么
- **D**：实际做了什么
- **C**：对比计划，哪些做得好，哪些有偏差
- **A**：下周调整什么

## 一句话案例

Plan："每天写 50 字" / Do：只有 4 天写了 / Check：前面 3 天没写是因为不知道写什么 / Act：下周提前准备 7 个话题清单。

## 在循环中的位置

周复盘是 Action Loop 的**反馈闭环**。承接"日执行"的实际数据，输出调整后的计划进入下一轮循环（回到选方向、定计划或调整微习惯）。
