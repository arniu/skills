# Action Loop

一套个人行动管理的循环框架。

你不需要更自律——你需要一个系统。

```
选方向 → 定计划 → 破障碍 → 日执行 → 周复盘
                                        ↕ 保状态
```

## 快速上手

- **建立全景**，从下方索引通读所有**卡片**。
- **深入理解**，挑一个问题，跟着**指南**照着做，卡住了再翻阅**深度**篇。
- **全程留意保状态**，精力不对先修身体。

## 模型说明

每个模型有三种阅读深度：

| 层级     | 什么时候看                                   |
| -------- | -------------------------------------------- |
| **卡片** | 快速了解一个模型是什么，或随时翻出来唤醒记忆 |
| **指南** | 第一次用这个模型，需要照着步骤做             |
| **深度** | 想理解背后的原理、变体用法，或卡住了找根因   |
