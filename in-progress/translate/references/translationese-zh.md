# 中文翻译腔

> 翻译腔：译文保留英文结构痕迹，读起来不像中文母语者写的。
> 以下每个条目对应一个具体的语言现象——看到英文 X，检查中文是否机械照搬为 Y。
>
> **这些不是禁用词。** 判断标准不是"有没有出现 Y"，而是"Y 是服务于中文表达，还是仅仅在复制英文语法"。部分条目标注了合理的保留场景。
>
> **主张的性质。** 仅 1.12、2.1、2.10 有语料库频次依据（见参考文献），其余是余光中、思果一系的文体规范建议——当风格建议用，不要当成"高频错误"的事实断言。
>
> **已入化的欧化。** "可行性""是……的""女士们、先生们""最……之一"等已吸收进标准中文的欧化形式，不当作翻译腔；凡条目中属此类者均已标"保留"。

## 一、语法结构

英文语法标记被照搬为对应的中文语法标记。

### 1.1 时态从句（when → 当……的时候）

**触发:** when + clause
**照搬:** 当……时/的时候
**修复:** 口语、叙事里常可删"当""的时候"，时序隐含在语序中
**保留:** 强调精确共时性或营造叙事悬念时——"当他推开门的那一刻，所有人都屏住了呼吸"，删掉会失去张力；技术条件句"当用户点击提交时""当同步完成时"是标准书面用法，也一样保留。

> When you finish the draft, send it to me.

- ✗ 当你写完稿子的时候，就寄给我吧。
- ✓ 稿子写完就寄给我吧。

> When in Rome, do as the Romans do.

- ✗ 当你在罗马的时候，像罗马人那样做。
- ✓ 既来罗马，就跟罗马人学。

### 1.2 被动语态（passive voice → 被）

**触发:** 英文被动式
**照搬:** 被 + V
**修复:** 改主动；确需被动换"受/遭/给/由/让/叫"。文言变体"为/被……所"也一样删"所"，用自然主动或简单被动
**保留:** 施动者未知、不重要或刻意隐藏时。"他被杀了"和"有人杀了他"信息焦点不同，前者是对的。

> His opinion isn't accepted.

- ✗ 他的意见不被大家接受。
- ✓ 大家都不接受他的意见。

> The window was broken.

- ✗ 窗户被打破了。（陈述状态时"被"多余）
- ✓ 窗户破了。（确指施动事件才用"被…打破"）

> He was deeply respected by the community.

- ✗ 他深为社区所敬重。
- ✓ 社区十分敬重他。

### 1.3 后置定语（relative clause → 长定语前置）

**触发:** who/which/that 引导的定语从句
**照搬:** 从句内容全部堆到名词前做定语
**修复:** 拆成后置短句或流水句；短定语前置是母语常态，病在把整个从句堆成超长定语
**保留:** 法律定义、技术规范中，前置定语保证精确性，不应拆散。

> She talked to the woman who has run the bakery on the corner for twenty years.

- ✗ 她跟那位在街角开了二十年面包店的女士谈了谈。
- ✓ 她跟那位女士谈了谈，对方在街角开了二十年面包店。

> They finally found the boy who had been missing for three days and was last seen near the train station.

- ✗ 他们终于找到了那个已经失踪了三天、最后一次有人看见是在火车站附近的男孩。
- ✓ 他们终于找到了那个男孩——他失踪了三天，最后一次现身是在火车站附近。

### 1.4 属格链（of-chain → 的……的……的）

**触发:** A of B of C
**照搬:** A的B的C
**修复:** 删掉不承担限定功能的"的"；用"之""而"替换；或拆成后置结构
**保留:** 法律/技术文本中，每个"的"承担精确的限定功能，不应为节奏牺牲准确。

> the implementation of the reform of the education system

- ✗ 教育系统的改革的实施
- ✓ 实施教育体系改革

> the analysis of the performance of the fund

- ✗ 基金的业绩的分析
- ✓ 基金业绩的分析

### 1.5 介词框架（in/on/at/in terms of → 在……中/上/里/方面）

**触发:** 英文介词短语做句首状语；in terms of / with respect to / regarding 抽象框架
**照搬:** 在 + N + 方位词（句首成串滥用）；在……方面/而言/层面
**修复:** 句首"在…中/上/里"常可删，让名词直接做话题；抽象框架"在……方面"常可整体删掉，直接说具体内容
**保留:** 存现句必留"在"——"书在桌上""他在房间里"；正式/技术文体中"在报告中""在 1939 年"、学术分类与报告小标题里"在……方面"都是标准书面语，不删。

> In the design phase, we validated the assumptions.

- ✗ 在设计阶段中，我们验证了假设。
- ✓ 设计阶段，我们验证了假设。

> This phone is better in terms of battery life.

- ✗ 这款手机在电池续航方面更好。
- ✓ 这款手机电池更耐用。

### 1.6 对象标记（of/for → 对……的……）

**触发:** description/analysis/study/understanding + of + N
**照搬:** 对 N 的 描述/分析/研究/理解
**修复:** 中文不需"对"来标记对象关系，直接说 N 的 N，或 N + N

> Write a brief, high-level description of the project.

- ✗ 写一段简短、高层次的对项目的描述。
- ✓ 写一段简短的项目概述。

### 1.7 方式状语（by/through → 通过……的方式）

**触发:** by/through + V-ing
**照搬:** 通过 + V + 的方式/手段
**修复:** 直接用动词，不加"通过"

> You can improve your health by exercising regularly.

- ✗ 通过定期锻炼的方式，你可以改善健康。
- ✓ 定期锻炼，就能改善健康。

### 1.8 受益者标记（for/to → 对于……来说）

**触发:** for X / to X（表评判或态度），成串出现时
**照搬:** 每句都来一个"对于……来说"
**修复:** 单用不删；成串时让名词直接做话题
**保留:** "对于送货员来说，速度很重要"是标准话题句，单用完全合法；病在连续几句都以"对于……来说"开头。

> Speed matters a lot for delivery drivers; punctuality matters for customers; cost matters for the platform.

- ✗ 对于送货员来说，速度很重要；对于顾客来说，准时很重要；对于平台来说，成本很重要。
- ✓ 送货员看重速度，顾客看重准时，平台看重成本。

### 1.9 代词保留（he/she/it/they → 它/他/她）

**触发:** 英文主语/宾语代词
**照搬:** 句句照译，不省
**修复:** 中文上下文清楚时省略代词

> He said he'd just parted from his two grandsons.

- ✗ 他说他刚跟他的两个孙子分开。
- ✓ 他说刚跟两个孙子分开。

### 1.10 结果从句（so…that → 如此……以至于）

**触发:** so + ADJ + that + clause
**照搬:** 如此 + ADJ + 以至于 + clause
**修复:** 用"得"字补语，或让因果隐含在语序里

> He was so angry that he couldn't speak.

- ✗ 他如此愤怒，以至于说不出话来。
- ✓ 他气得说不出话来。

### 1.11 否定提升（neg-raising）

**触发:** 英文把否定放在主句动词上，但逻辑上否定的是从句
**照搬:** 中文也跟着把否定放在主句动词上
**修复:** 否定词移到从句；或换用"没""从来没"

> I can't recall him ever refusing to help a friend.

- ✗ 我记不得他拒绝过帮助朋友。
- ✓ 他从没拒绝过帮朋友的忙。

> I don't think he will come.

- ✗ 我不认为他会来。
- ✓ 我觉得他不会来。

### 1.12 强调句式（be-passive → 是……的）

**触发:** 英文 be + 过去分词（陈述事实）
**照搬:** 是……的（中文强调式）
**修复:** 不是每个 be-verb 都要译"是"，直接陈述
**保留:** "是……的"是中文合法的强调式。"我是昨天到的"正确——问题只在于用它机械翻译英文非强调式被动。

> The meeting was held online.

- ✗ 会议是在线上举行的。（除非在回答"会议在哪儿开的"，否则无需强调式）
- ✓ 会议在线上举行。

### 1.13 倍数与百分比（increase by N times → 增长 N 倍）

**触发:** increase/grow by N times、as…as、decrease by N%
**照搬:** 把倍数的参照点弄错（increase by 3 times 译成"增加了 3 倍"、as tall as 译成"高 3 倍"）
**修复:** 3x faster 是"快三倍/是原来的 3 倍"，不是"增长三倍"；increase by N times 是"增加到 N 倍"，不是"增加了 N 倍"（那是 N+1 倍）
**保留:** "翻番""减半"是固定说法，改动前对照原文核对，不可因顺口改动。

> The new server is 3x faster than the old one.

- ✗ 新服务器的速度比旧服务器增长了 3 倍。
- ✓ 新服务器的速度是旧服务器的 3 倍。

### 1.14 形式主语（It is + ADJ + that/to → 重要的是/…很重要）

**触发:** It is + ADJ + that/to、It is believed/said that…
**照搬:** "它是……的"机械直译，或硬译形式主语
**修复:** 直接让 that 从句做话题——"准时到很重要""人们认为……"
**保留:** "值得注意的是""众所周知"等已成语的套语是标准用法，保留。

> It is important that you arrive on time.

- ✗ 它是重要的，你要准时到。
- ✓ 准时到很重要。

### 1.15 把字句缺用（disposal structure → 直陈）

**触发:** 英文及物动词 + 宾语 + 处所/结果补语
**照搬:** 回避"把"，直陈成"V + 宾语 + 补语"
**修复:** 宾语提前用"把"字句，这是中文处置结构的自然形式
**保留:** 无处置义的动词不用把（"看见""听见"不套把字句）。

> He moved the box into the room.

- ✗ 他移动箱子到房间里。
- ✓ 他把箱子搬进了房间。

### 1.16 时态标记过用（past tense → 已经/曾经/了）

**触发:** 英文过去时、完成体
**照搬:** 句句补"已经""曾经""了"标记时态
**修复:** 中文时态靠语境隐含，不要机械补时态标记；确需强调完成才用"已"
**保留:** 完成体的自然标记不删——"已经交付了""办好了"是标准说法；对比强调（"他以前来过，现在不来了"）时也保留。

> He worked there for five years.

- ✗ 他曾经在那里工作了五年。
- ✓ 他在那儿干了五年。

## 二、词汇对应

英文词项被机械映射到固定的中文词项，忽略上下文和搭配。

### 2.1 轻动词/虚化动词（make/do/give/conduct/予以/加以 → 进行/作出/予以）

**触发:** light verb + deverbal noun；正式/技术译文堆"予以""加以""给予"
**照搬:** 对 N 进行/作出 N；予以/加以/给予 + 名词化动词
**修复:** 直接用那个名词当动词："分析""调整""解决""考虑""支持"
**保留:** 正式语体（外交、法律、学术）中可增庄重感——"双方进行了友好磋商""予以高度重视"在公文/外交语境中得体；病在技术文档、产品文案里也照搬。

> We conducted a detailed analysis of the data.

- ✗ 我们对数据进行了详细的分析。
- ✓ 我们详细分析了数据。

> We will give full consideration to your proposal.

- ✗ 我们将对你的提案予以充分的考虑。
- ✓ 我们会充分考虑你的提案。

### 2.2 身份标记（as → 作为）

**触发:** as + 身份/角色
**照搬:** 作为一个……
**修复:** 改用"他是/他做/他这个"等自然说法

> As a husband, he is very affectionate.

- ✗ 作为一个丈夫，他十分深情。
- ✓ 他是个深情的丈夫。

### 2.3 部分标记（one of → 之一）

**触发:** one of + 复数名词
**照搬:** ……之一
**修复:** 没有明确可数范围时删；有明确可数范围时保留
**保留:** "他是三位候选人之一""李白是中国最伟大的诗人之一"都正确——有界集合里"之一"是标准母语；"他是最好的之一"错误（最高级缺范围）。

> He is one of the famous writers.

- ✗ 他是有名的作家之一。
- ✓ 他是位有名的作家。

### 2.4 话题标记（about/regarding → 关于/有关）

**触发:** about/regarding + N
**照搬:** 关于/有关 + N
**修复:** "关于/有关"删掉，N 直接做宾语或话题
**保留:** 正式标题中。"关于深化改革的决定"是标准公文格式。

> We discussed the plan, the budget, and the timeline.

- ✗ 我们讨论了关于计划、关于预算、以及关于时间表的事情。
- ✓ 我们讨论了计划、预算和时间表。

### 2.5 并列连接（and → 和/与/及）

**触发:** and 连接并列项
**照搬:** 和/与/及
**修复:** 中文并列常不需连接词，直接省略或用顿号

> In the park, we sang and danced.

- ✗ 我们在公园唱歌和跳舞。
- ✓ 我们在公园唱歌跳舞。

> John, James, Henry, and Danny are his good friends.

- ✗ 约翰、詹姆、亨利和丹尼都是好朋友。
- ✓ 约翰、詹姆、亨利、丹尼都是好朋友。

### 2.6 复数标记（-s/-es → 们）

**触发:** 英文复数名词（有生命/人）
**照搬:** N + 们
**修复:** 中文前后文已表多数时删"们"
**保留:** "女士们、先生们"是词汇化的标准套语，不视为翻译腔。

> All of the doctors in the city have disappeared.

- ✗ 这城市所有的医生们都消失了。
- ✓ 这城市所有的医生都消失了。

> All of the students have arrived.

- ✗ 所有的学生们都到了。
- ✓ 所有的学生都到了。

### 2.7 副词标记（-ly → 地）

**触发:** 英文 -ly 副词
**照搬:** XX 地
**修复:** 中文不需"地"时删掉；需状语时用自然搭配，不用机械照搬
**保留:** 中文自然使用"地"时保留（慢慢地、认真地、详细地）。

> We should actively explore new markets.

- ✗ 我们应该积极地探索新市场。
- ✓ 我们应该积极探索新市场。

### 2.8 属格代词（my/your/his/her → 我的/你的/他的/她的）

**触发:** 英文物主代词
**照搬:** 我的/你的/他的/她的
**修复:** 中文所属关系已明确时省译

> Unless you're willing to reduce your demands.

- ✗ 除非你愿意降低你的要求。
- ✓ 除非你愿意降低要求。

### 2.9 动词化后缀（-ize → 化）

**触发:** 英文 -ize 动词
**照搬:** XX化
**修复:** 用动词短语替代
**保留:** 已自然化的"最大化"（利益最大化、效果最大化）在商务/营销/产品文本中是标准词，不回避；只针对未固化的生造"XX化"。

> maximize the value of your ideas

- ✗ 最大化想法的价值
- ✓ 让你的想法发挥最大价值

### 2.10 名词化后缀（-ity/-ness → 性）

**触发:** 英文 -ity/-ness 抽象名词
**照搬:** XX性
**修复:** 用动词或形容词替代
**保留:** 已固化为术语的不回避。"可能性""科学性"在学术语境中是标准词。

> She praised the cleverness of the plan.

- ✗ 她称赞了这个计划的聪明性。
- ✓ 她称赞这个计划很聪明。

### 2.11 抽象主语（abstract noun as subject）

**触发:** 英文抽象名词做主语
**照搬:** XX 的 XX + 动词
**修复:** 改为人或具体事物做主语
**保留:** 学术/论述文体中。"经济的发展带来了环境压力"在论文中是标准中文。

> The decline in his income changed his lifestyle.

- ✗ 他收入的减少改变了生活方式。
- ✓ 他收入减少，因此改变了生活方式。

### 2.12 回指标记（former/latter → 前者/后者）

**触发:** the former / the latter
**照搬:** 前者 / 后者
**修复:** 口语、叙事中重复名词更自然；正式/学术/公文文体可保留"前者/后者"
**保留:** "公司兼顾成本与体验，前者决定利润，后者决定口碑"是标准书面语，不删。

> She compared the two proposals and found the latter more practical.

- ✗ 她比较了两个方案，发现后者更实用。
- ✓ 她比较了两个方案，发现第二个方案更实用。

### 2.13 将来标记（will → 将）

**触发:** will + V
**照搬:** 将 + V
**修复:** 用"会/就/要"；"将"偏正式书面语，口语中不自然
**保留:** 正式通告、新闻、公文中。"会议将于下周举行"是标准书面语。

> I will come.

- ✗ 我将前来。（口语里"将"生硬）
- ✓ 我会来的。

### 2.14 冗余副词（successfully → 成功地）

**触发:** successfully + V
**照搬:** 成功地 + V
**修复:** 动词已含结果，删"成功地"

> Sun Yat-sen successfully overthrew the Qing dynasty.

- ✗ 孙中山成功地推翻了清朝。
- ✓ 孙中山推翻了清朝。

### 2.15 来源标记（from → 从……来）

**触发:** from + 来源
**照搬:** 从……来的
**修复:** "从……来"限物理位移；表归属直接说

> children from poor families

- ✗ 从穷人家来的孩子
- ✓ 穷人家的孩子

### 2.16 关系标记（between → 之间）

**触发:** between + Ns
**照搬:** N 之间的 N
**修复:** 中文常可省"之间"，直接并词
**保留:** "两个城市之间的距离""朋友之间的信任"用"之间"完全标准，不删。

> the gap between rich and poor

- ✗ 富人与穷人之间的差距
- ✓ 贫富差距

### 2.17 尝试结构（try to → 试图）

**触发:** try to + V（口语/叙事语境）
**照搬:** 试图 + V
**修复:** 口语、叙事里用"试着/努力/想办法"，别用书面腔"试图"
**保留:** 正式/学术语体里"试图解释""试图证明"是合法标准词，保留。

> I tried to recall her name.

- ✗ 我试图回想她的名字。
- ✓ 我试着回想她的名字。

> He tried to explain the mistake.

- ✗ 他试图解释这个错误。
- ✓ 他试着解释这个错误。

### 2.18 冠词（a/an → 一个）

**触发:** 泛指 a/an + N
**照搬:** 一个 + N
**修复:** 泛指标记在中文不必要，省译
**保留:** 计数语义的"一个"必须保留——"给我一个苹果""买了三本书"是一+量词的中文计数，与英文冠词无关。

> He is a good man.

- ✗ 他是一个好人。
- ✓ 他是个好人。

### 2.19 存在句（contains/there is → 有/存在着）

**触发:** contains/has/exists（实主语）；there is/are（空主语）
**照搬:** 存在着 / 有 + 抽象名词堆砌
**修复:** 中文直接用形容词或动词表达，或换主动句
**保留:** "有"是标准存在标记——"教室里有人"正常；病在"存在着"的套板腔。

> Du Fu's poetry contains vivid depictions of the hardship of ordinary people.

- ✗ 杜甫的诗中存在着对百姓疾苦的生动刻画。
- ✓ 杜甫的诗生动刻画了百姓疾苦。

> There is intense competition in this market.

- ✗ 市场上存在着激烈的竞争。
- ✓ 这个市场竞争很激烈。

### 2.20 惯用搭配（make the switch → 做出转换）

**触发:** 英文惯用搭配/短语动词（make the switch、come across、bring about），仅当字面直译会产生无意义中文时
**照搬:** 按字面逐词直译（做出转换、碰见、带来）
**修复:** 理解整个短语的约定含义，用中文惯用说法表达（改用、偶然读到、促成）

> Thousands of founders have already made the switch to FlowDesk.

- ✗ 已有上千位创始人做出了到 FlowDesk 的转换。
- ✓ 已有上千位创始人改用 FlowDesk。

> I came across this article yesterday.

- ✗ 我昨天碰见了这篇文章。
- ✓ 我昨天偶然读到了这篇文章。

### 2.21 使役结构（allow/enable/let → 使/使得/允许）

**触发:** 无灵主语 + allow/enable/let（"X allows users to…"）
**照搬:** 使 / 使得 + 无灵主语直译（"新功能使得用户可以……"）
**修复:** 直接说"用户可以……"，去掉使役壳；确需保留时选具体动词（支持/让/允许）
**保留:** 技术规范里"本接口允许第三方调用"是标准书面语；病在句句都套"使/使得"。

> The new API allows developers to fetch data in real time.

- ✗ 新 API 使得开发者可以实时获取数据。
- ✓ 开发者可以用新 API 实时获取数据。

### 2.22 "随着……"套语（as … develops → 随着……的发展）

**触发:** as X develops/grows/evolves（时间状语从句）
**照搬:** 随着 N 的发展/的进步/的增长
**修复:** "N 成熟了，就…""N 一多，…"更自然；"随着"连用多个就成套板腔
**保留:** 正式论述里单个"随着……"可接受；病在句式化滥用。

> As the market matures, competition intensifies.

- ✗ 随着市场的不断发展，竞争日益激烈。
- ✓ 市场成熟了，竞争也跟着激烈起来。

### 2.23 万能形容词（available/various/quality/free → 可用的/各种的/高质量的/免费的）

**触发:** available/various/quality/free 等泛化修饰词
**照搬:** 一律直译成"可用的/各种的/高质量的/免费的"
**修复:** 按语境具体化或省略——"available options" 是"现有选项"，不是"可用的选项"
**保留:** 确指免费/质量时保留——"免费试用""质量保证"是标准词。

> Please select from the available options.

- ✗ 请从可用的选项中选择。
- ✓ 请在现有选项中选择。

### 2.24 情态动词（must/should/have to → 必须/应该/不得不）

**触发:** must/should/have to/can 连用
**照搬:** 一律译"必须""应该""不得不""可以"，句句带情态
**修复:** 按语气轻重选词，口语用"得/要/能"；语气弱或已含在语境中时省译
**保留:** 规范、指令性文本（"用户必须登录"）里"必须"是标准词，保留。

> If you have any problems, you should contact us.

- ✗ 如果你有任何问题，你应该联系我们。
- ✓ 有问题就联系我们。

## 三、篇章结构

英文的信息组织方式被照搬到中文，破坏中文的语篇习惯。

### 3.1 流水句与句长（repeated subject / uniform sentence length）

**触发:** 英文多句以同一主语开头、靠代词串联；或连续短句句长相近
**照搬:** 译文句句重复主语或保留相同的句长句式，破坏流水句结构
**修复:** 前句述题当后句主题，合并成流水句；首句出主语后后续省主语；并短句、拆长句、换句尾
**保留:** 短句的节奏本身就是强调时（连珠炮式的排比）不合并；每句信息量相差大、逻辑转折处保留独立成句。

> The company launched a product. It targets young professionals. It was developed over two years.

- ✗ 公司发布了一款产品。它面向年轻职场人。它开发了两年。
- ✓ 公司发布了一款产品，面向年轻职场人，研发历时两年。

> The team analyzed the data. They found three problems. They proposed a fix. Management approved it the next day.

- ✗ 团队分析了数据。他们发现了三个问题。他们提出了修复方案。管理层第二天就批准了。
- ✓ 团队分析了数据，发现三个问题。修复方案提上去，管理层第二天就批了。

### 3.2 显性关联词配对（because/although/not only → 因为……所以/虽然……但是/不仅……而且）

**触发:** because / although 从句；not only…but also / not…but / rather than
**照搬:** 因为……所以 / 虽然……但是 / 不仅……而且
**修复:** 中文逻辑常隐含在语序中，删显性连接词；递进常可省略显性配对，直接并列或靠语序
**保留:** 论证性文本中，显性连接词是必要的逻辑标记。
**阈值:** 一段中显性连接词扎堆（因为/所以、虽然/但是、然而、因此）时删减——逻辑关系清晰时直接用语序暗示；单用"虽然……但是"是标准普通话，不删。

> It was raining, but he went out. Because he had to catch the last train, he couldn't stay. However, the station was closed.

- ✗ 虽然天下着雨，但是他还出门了。因为他要赶末班车，所以他不能待着。然而，车站却关了。
- ✓ 天下着雨，他还是出门了。要赶末班车，不能待着。可车站关了。

> The app is not only fast but also easy to use.

- ✗ 这款应用不仅速度快，而且易于使用。
- ✓ 这款应用又快又好用。

### 3.3 长句不拆分（long sentence kept whole）

**触发:** 英文多分句长句（约三个分句以上，含 from/when/which 衔接）
**照搬:** 一逗到底，整句保留英文的衔接词与分句次序
**修复:** 按中文意群拆句、重排顺序、化长句为流水句
**保留:** 法律/技术定义中长句保证逻辑完整，可保留。

> The system retrieves the latest configuration from the server when the application starts, which ensures that all clients see the same settings.

- ✗ 系统在应用程序启动时从服务器检索最新配置，这确保了所有客户端看到相同的设置。
- ✓ 应用启动时，系统从服务器拉取最新配置，保证所有客户端看到的设置一致。

### 3.4 标点直译（破折号/括号/分号）

**触发:** 英文用破折号、括号、分号承载插入语/补充信息
**照搬:** 译文原样保留这些标点，打断中文语流
**修复:** 把插入成分化为独立分句、后置补充或直接并入主句
**保留:** 列表里的分号、列举用的括号在技术文档里是标准用法。

> The dashboard—which was redesigned last month—shows all metrics at a glance.

- ✗ 仪表盘——上个月重新设计过——一眼就能看到所有指标。
- ✓ 仪表盘上个月重新设计过，一眼就能看到所有指标。
