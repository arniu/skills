# 翻译方法论

翻译是**理解源文要做什么 → 忘记它的说法 → 用目标语重新实现。**

## 核心理念：融合功能对等与文本类型策略

两套理论帮你回答两个问题：

| 理论                 | 回答的问题                                               |
| -------------------- | -------------------------------------------------------- |
| **Newmark 文本类型** | 这段话的"自由度"有多大？该忠于作者，还是服务于读者？     |
| **Nida 功能对等**    | 目标语读者的反应和源语读者是否对等？**这是终极检验标准** |

---

## 事实保真：自由度的边界

自由度管的是**怎么说**，不是**说什么**。无论哪种文本类型，以下内容必须原样保真，重构句式时尤其容易顺手改掉它们：

- **数字与比较**：3x faster 是"快三倍"，不是"增长三倍"；"双倍""减半""排第几"都不能漂移
- **时间**："last week" 是上周，"over thirty years" 是三十年间，不能因顺口而改动
- **修饰与意象**：表达型的形容词和比喻是意义的载体——"effortless"是"不费力"，不是"随口说出"；换说法可以，程度和色彩不能漂移
- **专名与术语**：按[术语约定](#术语约定)处理，重构时不可替换或省略

自检："我改动原文里任何数字、时间或专名了吗？"——**这是自由度唯一的硬边界。**

## 文本类型：决定自由度

### 表达型（作者中心）

- **信号：** 第一人称、修辞、独特语气、个人故事
- **自由度：低。** 保留作者的句法和风格选择，不为流畅牺牲个性
- **防增饰：** 文学翻译不等于润色。原文的简洁、留白、甚至笨拙都是风格的一部分，要按照原文风格翻译。
- **自检：** "我是在保留作者的风格，还是在把它磨平？我有没有添加原文没有的修饰？"

### 信息型（事实中心）

- **信号：** 定义、数据、步骤、专业内容
- **自由度：中。** 信息准确优先，句法可重构让目标语更自然
- **自检：** "目标语读者能提取出同样的事实吗？"

### 呼唤型（读者中心）

- **信号：** 祈使句、第二人称称呼、设问、练习
- **自由度：高。** 让目标语读者感觉被直接对话，必要时大幅重构
- **节奏与力度：** 重构的目标是**更打动人，不是更平淡**。保留设问的钩子、祈使的短促、句末的落点——"烦不烦？"好过"你是否感到困扰？"。如果译文比原文平，就回重述。事实保真约束的是数字，不是火力。
- **自检：** "目标语读者会想行动吗？"

## 工作流

> **理解**（确定自由度）→ **重述**（脱源）→ **验证**

**理解** — 通读整段，判断它是讲述案例（信息型）、下定义（信息型）、说服读者（呼唤型），还是作者个人表达（表达型）。表面信号矛盾时，按文本的**主要目的**定类型。

**重述** — **脱源**是关键：合上原文，像一个用目标语写作的作者那样表达。专名按[术语约定](#术语约定)处理；拿不准的句式查[翻译腔参考文件](#翻译腔参考文件)。**整段脱源完成后再进验证。**

**验证** — 五道检查，全过才收工：

1. **朗读** — 译文通读一遍；能一口气读完的地方通过，**卡住、需要回读的地方就是翻译腔，回重述重来**
2. **回译测试** — 把译文译回英文；若回译结果和原文几乎一模一样，说明被原文结构绑架，回重述
3. **事实核对** — 对照原文核对数字、时间与专名（见[事实保真](#事实保真自由度的边界)）
4. **高频字扫描** — 搜这些字：的、和、当、被、有关、一个、之一、所、性、们；每个都要能解释为什么留它
5. **读者自检** — 回到所选[文本类型](#文本类型决定自由度)的**自检**问一句——Nida 读者反应，终极检验

## 术语约定

优先级从高到低：

1. **项目已定** — 术语表中的译法优先
2. **有通译** — 引文官方译本、专名标准译法、行业通用名优先
3. **无通译** — 专名保留源语；普通术语自行翻译并加注

加注格式：

- **目标语（源语）** — 首次出现于正文时加注，标题不加
- 有常用别称时：**目标语（源语；亦作"别译"）**
- 源语保持原貌
