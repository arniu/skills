# 提取术语表

## 工作流

**扫描** → **译写** → **整理**

**扫描** — 通读源文，标记每一个候选术语：领域特定概念、复合名词短语、专有名词、缩写词全称。**完成标志：** 逐词通读源文，无可遗漏的候选术语。

**译写** — 逐条确定中文译法，按 [译写规则](#译写规则) 执行。**完成标志：** 所有候选术语都有中文译法。

**整理** — 归入对应分类段落，按英文字母序排列，按 [输出格式](#输出格式) 分三个章节（术语、人名、书名）输出。完成后对照项目已有术语表，补全遗漏条目。**完成标志：** 三节术语表均已输出，无遗漏。

## 译写规则

1. **项目定译** — 直接沿用项目术语表译法
2. **行业通译** — 项目术语表中不存在时，查行业通行译法
3. **派生一致** — 按已有词根译法做一致性派生（如 engagement → 参与，则 reengagement → 再参与触发器）
4. **新定译法** — 以上都不存在时，从零翻译。新译法需同时满足：
   - **透明** — 读者能从中文看出对应哪个英文词（如 "learning loop" → "学习循环"）
   - **简明** — 2-5 字为佳，过长的短语要考虑能否缩写（如"最小可行产品" → 也可接受"MVP"）
   - **区分** — 同框架内的相关术语必须有可分辨的中文名（如 "core loop" / "learning loop" / "engagement loop" 共用"循环"但前缀不同）

## 输出格式

```markdown
| English | 中文 | 备注                 |
| ------- | ---- | -------------------- |
| term    | 译法 | 定义、语境或别名说明 |
```

**备注栏可选内容：** 简要定义、所属性框架（如"精通路径第三阶段"）、别名（亦作 XX）、参见相关条目（见 XX）。
